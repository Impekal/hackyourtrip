      📌 Diese Suche dauerhaft überwachen

      Die Suche hier zeigt einen Moment. Sparen entsteht erst durchs Beobachten: alle 3 Stunden prüft ein Automat diese Strecke, führt eine Preishistorie und meldet dir Preisstürze per Telegram oder E-Mail.

      Dafür kommt der Block unten in das Repo-Secret ROUTES_YAML_CONTENT – nicht in eine Datei: deine Reisepläne sollen nicht in einem öffentlichen Repo landen.

      1. Unten auf In Zwischenablage kopieren klicken.
      2. Secret ROUTES_YAML_CONTENT öffnen (GitHub → Settings → Secrets and variables → Actions).
      3. Ist es noch leer: alles einfügen. Beobachtest du schon Strecken: nur die Zeilen ab - id: unten anhängen – die Zeile routes: darf nur einmal vorkommen.
      4. Speichern. Der nächste Lauf nimmt die Strecke mit; sofort testen geht über den Actions-Tab → Check travel deals → Run workflow.

      Damit dich eine Meldung auch erreicht, muss ein Kanal hinterlegt sein: TELEGRAM_BOT_TOKEN + TELEGRAM_CHAT_ID oder die SMTP_*-Secrets. Fehlen beide, läuft die Prüfung zwar, aber niemand erfährt davon.
